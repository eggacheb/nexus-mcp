# 04: `read` 与 `write`

**What to build:** 让 AI 能真正读取和写入沙箱目录里的文件。读的时候看到行号，可以按片段读大文件；写的时候整文件覆盖；所有路径都必须在根目录内。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] `read` 返回带行号的内容，行号与文件真实行号一致
- [ ] `offset` 与 `limit` 按行切分，超出文件末尾时返回已有部分而不是报错
- [ ] 单次读取的行数有上限，超限时提示用 `offset` 继续
- [ ] 非 UTF-8 文件返回可读错误，不返回乱码
- [ ] `write` 整文件写入，内容按 UTF-8 编码，保留传入的换行风格
- [ ] 写入的父目录不存在时返回可读错误，不自动创建
- [ ] 越界路径（`..` 跳出、绝对路径指向根外、符号链接指向根外）一律拒绝，错误信息说明被拒绝的路径
- [ ] 根目录本身不可写，避免 AI 删掉沙箱根
- [ ] 路径解析对 Windows 盘符与反斜杠正确处理
