# 02: 本地控制面板

**What to build:** 服务同进程提供一个本地网页面板。打开浏览器就能看见服务是否正常、当前 MCP 地址、最近的日志，并且能不敲命令完成启停和改根目录。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 浏览器打开根路径能看到面板，一屏内包含：状态灯、MCP 地址、授权入口、根目录、日志、启停按钮
- [ ] 三个状态灯分别反映执行器、MCP 服务、隧道的真实状态，不是写死的
- [ ] MCP 地址可一键复制到剪贴板
- [ ] 面板上修改根目录后立即生效，并持久化到配置文件
- [ ] 日志区显示最近 100 行，可滚动，不泄露令牌
- [ ] 停/启/重载配置三个操作可用，操作后状态灯随之变化
- [ ] 不引入 Tauri、Electron 或任何桌面框架，面板由服务自身提供静态资源
- [ ] 面板接口不接受跨站请求写操作（避免本地网页被别的页面驱动）
