# 11: 分发打包

**What to build:** 把整套东西打包成一个 zip，别人下载解压、填一个令牌就能用，不需要在机器上装 Rust 或 Node。这是最后一张票，前面全部跑通之后再做。

**Blocked by:** 03, 04, 05, 06, 07, 08, 09, 10

**Status:** ready-for-agent

- [ ] 产出单个 zip：两个可执行文件 + `config.json` + 启动脚本 + 简短说明
- [ ] 解压后双击启动脚本即可运行，不需要安装 Node、Rust 或任何开发工具链
- [ ] 首次运行在缺少配置时生成默认配置，不直接崩溃
- [ ] 配置读取优先级正确：环境变量 > 可执行文件同目录 > 内置默认
- [ ] 在一台没有装过开发工具链的机器上验证：启动、连上、调一次 `read`
- [ ] 面板在打包版本里能正常打开，地址与端口正确
- [ ] 版本号写进产物，面板上可见
